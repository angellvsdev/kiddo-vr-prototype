# 🥽 Kiddo VR — Subproyecto WebXR Prototype

Este directorio contiene la aplicación cliente construida con **Vite** y **Three.js** para el prototipo inmersivo de Realidad Virtual con Meta Quest 3 y pedales interactivos.

Para consultar la **documentación completa, arquitectura detallada, diagramas de flujo y especificaciones del puente de hardware externo**, consulta el [README principal en la raíz del repositorio](../README.md).

---

## ⚡ Inicio Rápido

```bash
# 1. Instalar dependencias
npm install

# 2. Levantar el servidor de desarrollo seguro (HTTPS)
npm run dev

# 3. Construir paquete para producción
npm run build
```

Acceso desde Meta Quest Browser: `https://<TU-IP-LOCAL>:5173` o vía túnel Cloudflare.
